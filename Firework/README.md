# 나의 불꽃놀이 🎆

화면을 누르면 그 자리에서 불꽃이 터지는 나만의 가상 불꽃놀이 웹 앱입니다.
서버 없이 정적 파일만으로 동작하고, 휴대폰 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

## 주요 기능
- **직접 쏘기**: 화면을 누르면 아래에서 불꽃이 솟아올라 누른 높이에서 터집니다. 길게 누르고 움직이면 연속 발사, 여러 손가락으로 동시에 발사할 수 있어요.
- **불꽃 10종**: 국화, 모란, 버드나무, 고리, 하트, 별, 이중 폭발, 폭포, 팡팡, 무작위
- **색상 7종**: 무지개, 금빛, 파랑·청록, 분홍·보라, 빨강·주황, 흰색, 무작위 (중심·가장자리 그라데이션)
- **자동 쇼 4종**: 잔잔한 밤, 축제, 로맨틱, 그랜드 피날레
- **문구 불꽃**: 12자까지의 글자를 불꽃으로 그려요 (자주 쓰는 문구 저장)
- **나만의 쇼**: 녹화 → 이름 붙여 저장 → 재생(0.5x/1x/2x, 반복), 이름 변경, 복제, 삭제
- **카운트다운**: 정한 시각이 되면 쇼와 "새해 복 많이 받으세요" 문구 불꽃이 자동으로 시작
- **소리·진동**: 발사·폭발·잔 불꽃 소리를 코드로 합성 (좌우 위치, 거리감), 폭발 시 진동
- **사진 저장**, **전체 화면**, **화면 꺼짐 방지**, **배경 4종**, **성능 자동 조절**, **라이트/다크 모드**

## GitHub Pages에 올리기
1. GitHub에 로그인하고 오른쪽 위 **+ → New repository**로 새 저장소를 만듭니다. (예: `fireworks`, Public)
2. 저장소 화면에서 **Add file → Upload files**를 누르고, `불꽃놀이` 폴더 **안의** 파일과 폴더를 모두 끌어다 놓습니다.
   - `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `.nojekyll`, `icons` 폴더
   - `.nojekyll`처럼 점으로 시작하는 파일은 보이지 않을 수 있어요. 안 올라갔다면 **Add file → Create new file**에서 이름을 `.nojekyll`로 하고 빈 채로 저장하세요.
3. **Commit changes**를 누릅니다.
4. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 정하고 **Save**.
5. 1~2분 뒤 `https://사용자명.github.io/저장소명/` 에서 열립니다.

## 휴대폰 홈 화면에 추가하기
- **안드로이드 (크롬)**: 사이트를 연 뒤 오른쪽 위 **⋮ → 홈 화면에 추가**(또는 **앱 설치**) → **추가**
- **아이폰 (사파리)**: 사이트를 연 뒤 아래쪽 **공유 버튼(□↑) → 홈 화면에 추가** → **추가**
  - 아이폰은 사파리에서만 홈 화면 추가가 됩니다.

## 저장·불러오기
- **메뉴 → 저장·불러오기 → 전체 저장**: 내 쇼, 저장한 문구, 카운트다운 설정, 모든 설정을
  `불꽃놀이_백업_2026-11-23.json` 같은 파일 하나로 저장합니다. 휴대폰에서는 공유 창이 열리니
  **파일에 저장**이나 드라이브를 고르세요.
- **전체 불러오기**: 파일을 고르면 내용을 먼저 보여준 뒤 고를 수 있어요.
  - **합치기(기본)**: 지금 데이터를 그대로 두고 파일 내용을 더합니다. 같은 쇼는 더 최근에 수정된 쪽을 남기고, 이름만 같은 다른 쇼는 둘 다 두고 "(가져옴)"을 붙입니다.
  - **덮어쓰기**: 두 번 확인한 뒤 지금 데이터를 파일 내용으로 바꿉니다.
  - 잘못된 파일이면 이유를 알려주고 기존 데이터는 그대로 둡니다. 저장 도중 실패하면 원래대로 되돌립니다.
- **쇼 한 개씩**: 쇼 목록에서 쇼 옆의 저장 버튼으로 쇼 파일을 만들어 친구에게 보내고, 받은 파일은 **쇼 불러오기**로 엽니다.
- **자동 보관본**: 덮어쓰기 불러오기나 전체 삭제 직전의 데이터를 최근 2개까지 앱 안에 보관합니다. **설정 → 자동 보관본**에서 복원할 수 있어요.
- 30일 넘게 전체 저장을 하지 않았고 내 쇼가 3개 이상이면 메뉴에 저장 안내가 나타납니다.

## 주의사항
- 데이터는 **이 기기의 이 브라우저에만** 저장됩니다. 다른 기기와 자동으로 맞춰지지 않아요.
- 브라우저의 **사이트 데이터(쿠키·저장 공간)를 지우면 내 쇼도 함께 지워집니다.** 정기적으로 전체 저장을 해 두세요.
- **무음 모드·저전력 모드**에서는 소리가 나지 않거나 성능이 낮아질 수 있어요. 소리는 화면을 처음 누른 뒤부터 납니다.
- **깜빡이는 빛이 나옵니다.** 빛에 민감하다면 설정에서 **섬광 효과 줄이기**를 켜 주세요.
- **카운트다운은 앱을 열어 둔 상태에서만** 동작합니다. 화면이 꺼지지 않게 충전기를 연결해 두면 좋아요.
- 파일을 수정해서 다시 올렸는데 반영이 안 되면 `sw.js` 맨 위의 `CACHE_VERSION` 값을 올리세요. (예: `'v1'` → `'v2'`)
- 아이콘을 바꿨다면 홈 화면 아이콘은 **지우고 다시 추가**해야 바뀝니다.
- 글꼴(Pretendard)을 불러오지 못해도 기기 기본 글꼴로 정상 동작합니다.

## 파일 구성
```
불꽃놀이/
├─ index.html            앱 본체 (HTML, CSS, JS)
├─ manifest.webmanifest  홈 화면 앱 설정
├─ sw.js                 오프라인 실행용 서비스 워커
├─ icons/                앱 아이콘 (192, 512, 마스커블 512, 애플 180, SVG)
├─ .nojekyll             GitHub Pages 설정용 빈 파일
└─ README.md             이 설명서
```
